## 3. The Core Problem

No frequency-compression hypothesis survives the hard rejection rules because:

1. **"Try H4"** is not a single hypothesis — it's a search pattern. We'd need to define H4 BOS, H4 FVG, H4 OB, H4 entry, H4 stop, H4 horizon — essentially a new R3 from scratch.

2. **Episode aggregation** is genuinely interesting but introduces new degrees of freedom (what defines an episode?) that would require their own qualification.

3. **The M1 gross edge is +1.01 bps.** This is tiny. Even if higher timeframes have larger edges, we have no basis for predicting how much larger. The edge might be +5 bps on H4, or it might be +0.5 bps. We don't know.

4. **The cost structure is fixed.** Spread is a property of the broker/market, not the timeframe. Round-trip cost stays ~18 bps regardless of timeframe. The only way to improve the edge/cost ratio is to increase the edge per trade.
