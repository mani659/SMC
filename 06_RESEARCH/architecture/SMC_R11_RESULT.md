Why R11 was required:
  R10 established the four-level hierarchy but lacked explicit framework
  for rare-event discovery and specialist-module combination governance.

Rare-event principle:
  Rare events can qualify if evidence is sufficient.
  Frequency, evidence, magnitude, contribution, scalability are separate dimensions.

Minimum economic threshold:
  E[R_net] > 0 after realistic frozen costs.
  No universal minimum bps/dollars/returns/trades.

Evidence sufficiency:
  Report: independent N, calendar, CI, OOS, magnitude, cost, dependence.
  Control Session decides sufficiency per phenomenon.
  No universal N threshold.

Rare-event inconclusive state:
  INCONCLUSIVE - EVIDENCE INSUFFICIENT
  Prevents false rejection and false acceptance.

Standalone module:
  Own positive expectancy. May be rare. Does not need continuous activity.

Specialist module:
  Active only under predefined state.
  Regime definition frozen independently of module outcomes.

Trade-generator module:
  Produces own positive expectancy.

Conditioning module:
  Must have independently defensible economic role.
  Cannot be justified by improving another strategy's PnL.

Suppressor module:
  Avoids situations where base module expectancy is worse.
  Requires own defensible hypothesis.

Scientific independence:
  Information source is not duplicate of same structural event.

Economic independence:
  Module has distinct payoff mechanism.

Sampling independence:
  Validation evidence not entirely dependent on same small event set.

Module complementarity:
  Distinct domains. Both independently qualified before combination.
  Activation overlap, conflict resolution, capital allocation frozen.

Module silence:
  Allowed. Value not measured by trade count.
  Measured by: conditional expectancy, evidence, quality, contribution.

Capital contribution:
  Positive expectancy ≠ scalable.
  Deployment layer handles scale, risk, capacity.

Architecture A:
  One independently validated killer strategy.

Architecture B:
  Small number of validated specialist modules with router.

Combination rule:
  Forbidden: test every combination, pick best.
  Allowed: both independently validated, interaction defined ex ante,
  combined hypothesis predeclared, combined OOS untouched.

Failed-artifact reuse rule:
  Scientifically informative, not automatically a filter/confirm.
  Reuse requires new hypothesis with new methodology cycle.

Evidence ladder:
  M0 (Phenomenon) -> M1 (Scientific) -> M2 (Predictive) ->
  M3 (Economic Candidate) -> M4 (Validated Module) -> M5 (Deployment)
